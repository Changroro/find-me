# Find Me 설정

이 파일의 위치에서 두 단계 위가 플러그인 루트다. 현재 작업 디렉터리나 고정된 설치 경로를 가정하지 않는다. 공통 도우미는 `<플러그인 루트>/scripts/config.py`이고 Python 실행에는 `uv run python`을 사용한다. `uv`가 없으면 설치가 필요하다고 알리고 중단한다.

사용자 JSON의 기본 경로는 `~/.config/find-me/config.json`이다. 두 도구가 같은 파일을 사용한다. 사용자가 `FIND_ME_CONFIG` 환경 변수나 명시적인 다른 설정 경로를 지정했으면 그 경로를 사용한다. 사용자 JSON과 기록은 플러그인 루트 밖에 둔다.

먼저 `uv run python <도우미> template`로 배포된 기본 JSON을 읽는다. 설정 파일이 이미 있으면 현재 내용을 보여 주고 덮어쓰지 않는다. 프롬프트 변경은 fix-record로 안내한다.

사용자에게 다음을 입력받는다. 아직 답하지 않은 항목만 묻는다.

- 기록을 저장할 Markdown 문서의 절대 경로. Obsidian은 선택 사항이며 볼트 경로를 자동 선택하지 않는다.
- 기록할 주제. 기본 JSON의 전체 주제를 기본 선택지로 보여 주되 사용자가 선택하거나 추가하게 한다. 각 주제는 공백과 #이 없는 이름이다.

선택된 경로·주제와 기본 프롬프트를 복사한다는 점을 보여 준다. 사용자가 이미 이 설정의 저장을 승인했다면 다시 묻지 않고 진행한다. 기록 경로의 폴더는 필요하면 만들며 기존 기록은 보존한다.

초기 설정의 답변이나 주제 선택 자체를 사용자의 성향으로 해석해 기록하지 않는다.

`uv run python <도우미> setup --record-path '<문서 절대 경로>' --topics '<주제1>' '<주제2>'`를 실행한다. 별도 설정 경로는 도우미 바로 뒤에 `--config '<설정 절대 경로>'`를 넣는다. 사용자 입력은 안전하게 셸 인자로 전달한다.

성공 후 사용자 JSON 경로, 기록 경로, 선택 주제를 알린다. 기본 프롬프트의 복사본으로 write-record가 동작하며 fix-record는 복사본만 수정한다고 설명한다. 실제 기록을 만들거나 플러그인 설치본·기본 JSON을 수정하지 않는다.
