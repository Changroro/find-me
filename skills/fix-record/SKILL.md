# 기록 프롬프트 수정

이 파일의 위치에서 두 단계 위가 플러그인 루트다. `<플러그인 루트>/scripts/config.py`를 `uv run python`으로 실행한다. `uv`가 없으면 설치가 필요하다고 알리고 중단한다.

`uv run python <도우미> show`로 현재 사용자 JSON과 revision을 읽는다. 기본 경로는 `~/.config/find-me/config.json`이다. `FIND_ME_CONFIG` 또는 사용자가 지정한 `--config`를 다른 스킬과 동일하게 사용한다. 설정이 없으면 setup을 안내하고 중단한다. 배포된 기본 프롬프트로 대체하지 않는다.

사용자의 피드백을 읽고 없으면 무엇을 바꿀지 묻는다. 대상 기록은 사용자가 제공한 내용이나 설정된 기록 문서에서 확인한다. 사용자의 말을 단순한 프로젝트명 치환으로 처리하지 말고 이후 기록에도 적용할 수 있는 기준으로 바꾼다. 피드백에 없는 취향이나 요구를 추가하지 않는다.

“아무거나 기록한다”, “반복이 많다”는 피드백은 선별 기준의 문제다. 직접적인 자기 이야기 또는 독립된 상황의 충분한 근거, 자기 이해에 도움이 되는 구체성, 과거와 다른 새로운 정보가 있는지를 통과 조건으로 다듬는다. “더 의미 있게” 같은 추상적인 지시만 덧붙이지 않는다. write-record의 과거 비교와 모순·이상에 대한 사용자 확인 절차를 무효화하지 않는다. 이 피드백 자체를 새 성향 기록으로 만들지 않는다.

현재 `settings.prompt`에서 필요한 부분만 수정한다. 기존 개인 규칙을 보존하고 충돌하는 문장은 고쳐 상반된 지침을 계속 덧붙이지 않는다. 수정 전후의 규칙과 같은 맥락을 사용한 짧은 기록 예시를 보여 준다. 피드백이 모호하면 확인하고, 구체적인 수정이 이미 승인됐다면 재승인을 요구하지 않는다.

수정한 전체 프롬프트를 표준 입력으로 전달한다.

```sh
uv run python '<도우미 절대 경로>' fix --expected '<show가 반환한 revision>' <<'FIND_ME_PROMPT'
수정된 사용자 프롬프트 전체
FIND_ME_PROMPT
```

내용 확장이 없는 따옴표 구분자를 사용하고, 본문에 등장하면 다른 구분자로 바꾼다. 실제 경로·revision·프롬프트를 넣어 실행하며 사용자 지정 설정 경로가 있으면 동일한 `--config`를 사용한다. 설정이 변경되어 실패하면 다시 읽고 기존 개인 규칙과 수정안을 맞춘다.

이 명령은 사용자 JSON의 `prompt`만 변경한다. 저장 경로·주제·기존 기록·배포 기본 JSON·SKILL.md는 변경하지 않는다. 수정된 프롬프트는 다음 write-record 호출부터 적용된다. 사용자 JSON을 Git에 추가하거나 커밋하지 않는다.
